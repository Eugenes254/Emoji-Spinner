# 🎡 Emoji Circle Spinner

A fun and interactive **circular emoji spinner** that spins like a wheel of fortune 🎯
Perfect for games, random choices, or just vibing with animations 😄

---

## 🚀 Features

* 🎡 Circular spinning wheel design
* 🎲 Random emoji selection
* ⚡ Smooth spin animations
* 🎯 Pointer-based result selection
* 📱 Responsive (works on mobile & desktop)
* 🔁 Spin again anytime

---

## 🧠 How It Works

* Emojis are arranged in a **circle (wheel)**
* When you click **Spin**, the wheel rotates 🎡
* A fixed **pointer** selects the final emoji when the spin stops

Example emojis on the wheel:

```
😂 😎 🔥 🍕 🎉 💀 🚀 😍 🐍 🍀
```

---

## 🛠️ Tech Stack

* HTML (structure)
* CSS (circle layout + animations)
* JavaScript (spin logic & randomness)

## 📦 Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/emoji-circle-spinner.git
```

2. Navigate into the project:

```bash
cd emoji-circle-spinner
```

3. Open `index.html` in your browser

---

## ▶️ Usage

1. Click the **Spin** button 🎯
2. Watch the wheel rotate 🎡
3. The pointer selects a random emoji
4. Repeat and enjoy 😄
